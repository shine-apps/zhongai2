## 1. 项目概述

### 1.1 任务重述

基于"众爱联盟公益积分微信小程序"产品需求文档（PRD），设计一套完整的前后端技术方案：

| 维度 | 说明 |
|------|------|
| **目标** | 为公益组织打造"双积分制"（活动积分 + 捐助积分）志愿者管理平台 |
| **前端** | Uniapp + wot-starter-v2 模板，编译目标为微信小程序 + H5 |
| **后端** | Nuxt v4 提供 API 服务 + 后台管理界面，UI 使用 Element Plus |
| **数据库** | PostgreSQL |
| **输出** | Markdown 格式的详细设计文档 |

### 2.2 技术选型明细

| 层级 | 技术 | 版本 | 用途 |
|------|------|------|------|
| **前端框架** | Uniapp | latest | 跨端开发（微信小程序 + H5） |
| **前端UI** | wot-starter-v2 (Wot Design Uni) | v2 | 小程序/H5 组件库 |
| **CSS方案** | SCSS (sass-embedded) | latest | 全局样式与主题变量 |
| **后端框架** | Nuxt | v4 | API服务 + SSR管理后台 |
| **后端UI** | Element Plus | latest | 管理后台组件库 |
| **ORM** | Drizzle ORM | latest | 类型安全的数据库操作 |
| **数据库** | PostgreSQL | 16+ | 主数据库 |
| **文件存储** | 本地/OSS | - | 图片、凭证文件存储 |
| **富文本编辑** | WangEditor V5 | v5 | 管理后台富文本编辑 |
| **HTML渲染** | mp-html | latest | 小程序端富文本展示 |
| **认证** | JWT + 微信登录 | - | 用户身份认证 |

#### 4.3.3 签到验证逻辑

```typescript
// GPS签到验证伪代码
async function verifyGpsCheckin(activityId: string, userId: string, lat: number, lng: number) {
  const activity = await getActivity(activityId)

  // 1. 检查活动状态
  if (activity.status !== 'ongoing') throw new Error('活动未在进行中')

  // 2. 检查时间范围
  const now = new Date()
  if (now < activity.startTime || now > activity.endTime) {
    throw new Error('不在活动时间范围内')
  }

  // 3. 检查是否已报名
  const registration = await getRegistration(activityId, userId)
  if (!registration || registration.status !== 'approved') {
    throw new Error('未报名或报名未通过')
  }

  // 4. 检查是否已签到
  const existing = await getCheckin(activityId, userId)
  if (existing) throw new Error('已签到，请勿重复签到')

  // 5. GPS距离验证（使用Haversine公式）
  const distance = calculateDistance(lat, lng, activity.latitude, activity.longitude)
  if (distance > activity.checkinRadius) {
    throw new Error(`距离活动地点${distance.toFixed(0)}米，超出签到范围`)
  }

  // 6. 创建签到记录
  return await createCheckin({
    activityId, userId,
    checkinType: 'gps',
    latitude: lat,
    longitude: lng,
  })
}
```

```typescript
// stores/user.ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import type { UserInfo } from '@/types/user'
import { getToken, setToken, removeToken } from '@/utils/storage'
import * as authApi from '@/services/auth'
import * as userApi from '@/services/user'

export const useUserStore = defineStore('user', () => {
  // State
  const token = ref<string>(getToken())
  const refreshToken = ref<string>(getRefreshToken())
  const userInfo = ref<UserInfo | null>(getUserInfo())

  // Getters
  const isLoggedIn = computed<boolean>(() => !!token.value)
  const isAdmin = computed<boolean>(() => userInfo.value?.role === 'admin')
  const isLeader = computed<boolean>(
    () => userInfo.value?.role === 'leader' || userInfo.value?.role === 'admin'
  )

  // Actions
  async function login(code: string, nickname?: string, avatarUrl?: string) {
    const result = await authApi.login(code, nickname, avatarUrl)
    token.value = result.token
    refreshToken.value = result.refreshToken
    userInfo.value = result.user
    setToken(result.token)
    setRefreshToken(result.refreshToken)
    setUserInfo(result.user)
  }

  async function fetchUserInfo() {
    const info = await userApi.getMyInfo()
    userInfo.value = info
    setUserInfo(info)
  }

  function logout() {
    token.value = ''
    refreshToken.value = ''
    userInfo.value = null
    removeToken()
    removeRefreshToken()
    removeUserInfo()
    uni.reLaunch({ url: '/pages/login/index' })
  }

  return { token, refreshToken, userInfo, isLoggedIn, isAdmin, isLeader, login, fetchUserInfo, logout }
})
```

### 5.4 前端请求封装

```typescript
// utils/request.ts
import type { ApiResponse } from '@/types/api'

const BASE_URL: string = import.meta.env.VITE_API_BASE_URL || '/api'

interface RequestOptions {
  showLoading?: boolean
  loadingText?: string
  showError?: boolean
  header?: Record<string, string>
}

interface RequestParams {
  url: string
  method?: 'GET' | 'POST' | 'PUT' | 'PATCH' | 'DELETE'
  data?: any
}

/**
 * 封装 uni.request 为 Promise
 * - 自动附加 JWT Token（Bearer）
 * - 自动附加 X-Platform / X-Version 头
 * - 401 自动清除 token 并跳转登录页
 * - 可选 loading 和错误提示
 */
export function request<T = any>(
  options: RequestParams,
  requestOptions: RequestOptions = {}
): Promise<T> {
  const { showLoading = false, loadingText = '加载中...', showError = true, header = {} } = requestOptions

  // 获取 token
  const token = uni.getStorageSync('token') || ''

  const headers: Record<string, string> = {
    'Content-Type': 'application/json',
    ...header,
  }

  if (token) {
    headers['Authorization'] = `Bearer ${token}`
  }

  // 平台和版本信息
  headers['X-Platform'] = uni.getSystemInfoSync().platform || 'unknown'
  // #ifdef MP-WEIXIN
  headers['X-Version'] = uni.getAccountInfoSync().miniProgram.version || '1.0.0'
  // #endif
  // #ifndef MP-WEIXIN
  headers['X-Version'] = '1.0.0'
  // #endif

  if (showLoading) {
    uni.showLoading({ title: loadingText, mask: true })
  }

  return new Promise<T>((resolve, reject) => {
    uni.request({
      url: BASE_URL + options.url,
      method: options.method || 'GET',
      data: options.data,
      header: headers,
      success: (res) => {
        const response = res.data as ApiResponse<T>
        if (response.code === 0) {
          resolve(response.data)
        } else if (response.code === 401) {
          uni.removeStorageSync('token')
          uni.removeStorageSync('refreshToken')
          uni.showToast({ title: '登录已过期，请重新登录', icon: 'none' })
          setTimeout(() => uni.reLaunch({ url: '/pages/login/index' }), 1500)
          reject(new Error('登录已过期'))
        } else {
          if (showError) uni.showToast({ title: response.message, icon: 'none' })
          reject(new Error(response.message))
        }
      },
      fail: (err) => {
        if (showError) uni.showToast({ title: '网络异常', icon: 'none' })
        reject(err)
      },
      complete: () => {
        if (showLoading) uni.hideLoading()
      },
    })
  })
}

/** 快捷方法 */
export const get = <T>(url: string, opts?: RequestOptions) => request<T>({ url, method: 'GET' }, opts)
export const post = <T>(url: string, data?: any, opts?: RequestOptions) => request<T>({ url, method: 'POST', data }, opts)
export const patch = <T>(url: string, data?: any, opts?: RequestOptions) => request<T>({ url, method: 'PATCH', data }, opts)
export const del = <T>(url: string, opts?: RequestOptions) => request<T>({ url, method: 'DELETE' }, opts)
export const upload = <T>(url: string, filePath: string, opts?: RequestOptions) => {
  // 文件上传封装（uni.uploadFile）
}
```

## 6. 接口规范与安全设计

### 6.1 接口规范

#### 6.1.1 请求头规范

| Header | 说明 | 示例 |
|--------|------|------|
| `Content-Type` | 请求体格式 | `application/json` |
| `Authorization` | JWT Token | `Bearer eyJhbGciOi...` |
| `X-Platform` | 客户端平台 | `wechat-mp` / `h5` |
| `X-Version` | 客户端版本 | `1.0.0` |

#### 6.1.2 错误码定义

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未登录或Token过期 |
| 403 | 无权限访问 |
| 404 | 资源不存在 |
| 409 | 资源冲突（如重复报名） |
| 422 | 业务校验失败 |
| 500 | 服务器内部错误 |

#### 6.1.3 分页规范

请求参数：`page`（页码，从1开始）、`pageSize`（每页条数，默认10，最大50）

### 6.2 安全设计

| 安全措施 | 实现方式 |
|----------|----------|
| **认证** | JWT + Refresh Token 双Token机制（access 7天 / refresh 30天） |
| **微信登录** | wx.login + wx.getPhoneNumber → 后端code2session → 绑定手机号 → 生成JWT |
| **管理员登录** | 用户名+密码 → 生成JWT（`admin-login.post.ts`） |
| **API 权限控制** | Nitro 服务端中间件 `server/middleware/auth.ts` 校验 JWT Token |
| **后台路由鉴权** | Nuxt 路由中间件 `app/middleware/admin-auth.ts` 检查 localStorage `admin_token` |
| **数据加密** | 身份证号 AES 加密存储 |
| **SQL注入防护** | Drizzle ORM 参数化查询 |
| **文件上传** | 限制文件类型、大小，图片压缩 |
| **HTTPS** | 全站 HTTPS |
| **CORS** | Nuxt routeRules 配置允许的来源和方法 |

### 6.3 文件上传设计

```
上传流程：
1. 前端选择图片/视频 → uni.chooseImage / uni.chooseVideo
2. 前端压缩图片 → uni.compressImage（视频由后端转码压缩）
3. 前端上传 → POST /api/upload
4. 后端接收 → 校验类型/大小 → 存储到本地/OSS
5. 返回文件URL → 前端使用

支持的文件类型：
- 图片：jpg, jpeg, png, gif, webp（最大5MB）
- 视频：mp4, mov（最大100MB，活动视频/照片使用）
- 文档：pdf（最大10MB，用于凭证）
```
