## 🎯 项目概述

### 项目定位

**众爱联盟**是一个基于区块链思维设计的志愿者积分管理平台，旨在通过积分激励机制鼓励更多人参与公益活动和捐赠行为。

### 核心理念

- 👍 鼓励参与：通过积分奖励机制激励志愿者
- 📊 透明管理：完整的捐赠和积分记录体系
- 🏆 荣誉体系：建立志愿者成长和荣誉机制

---

## 🛠️ 核心功能

### 1. 活动管理

- ✅ 创建和发布公益活动
- ✅ 志愿者在线报名
- ✅ 活动签到管理
- ✅ 积分自动发放

### 2. 积分系统

- ✅ 积分获取（活动参与、捐赠、实名认证）
- ✅ 积分消费（商品兑换、特权服务）

- ✅ 积分交易记录

### 3. 捐赠管理

- ✅ 资金捐赠

- ✅ 捐赠审核流程
- ✅ 捐赠追溯记录

### 4. 用户管理

- ✅ 志愿者注册
- ✅ 实名认证
- ✅ 用户冻结/解冻
- ✅ 荣誉等级体系

## 💻 管理后台 - 捐赠审核

### 审核流程

1. 用户提交捐赠申请
2. 管理员查看详情
3. 验证捐赠凭证
4. 审核通过/拒绝
5. 发放相应积分

### 捐赠类型

- 💵 **资金捐赠**：在线支付
- 📦 **物资捐赠**：线下交付，上传凭证

## 🏗️ 技术架构

### 后端技术栈

- **框架**：Nuxt 4 (TypeScript)
- **数据库**：PostgreSQL + Drizzle ORM
- **认证**：JWT Token
- **加密**：身份证号AES-256-GCM加密
- **密码**：bcrypt 哈希存储

### 前端技术栈

- **移动端**：UniApp (Vue 3)
- **管理后台**：Nuxt 4 + Element Plus
- **小程序**：微信小程序

## 🚀 快速启动

### 后端启动

```bash
cd /workspace/server
npm install
npm run db:migrate
npm run seed:admin
export $(cat .env | xargs)
npm run start
```

### H5开发启动

```bash
cd /workspace/miniapp
npm install
npm run dev:h5
```
